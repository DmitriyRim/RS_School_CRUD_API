## CRUD API
### Prerequisites
1. Clone your newly created repo locally: https://github.com/DmitriyRim/RS_School_CRUD_API  
2. Go to folder `RS_School_CRUD_API`  
3. Go to the develop branch
```
git checkout develop
```
4. To install all dependencies use 
```
npm install
```  
5. Rename the `.env.example` file to `.env`

### Commands
- `start:prod` - The application is run in production mode 
- `start:dev` - The application is run in development mode using `nodemon`
- `format` - Starts formatting the code
- `lint` - Starts checking the source code for compliance with the established rules.
